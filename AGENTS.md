# Agent roles and working rules

This repository follows the project responsibilities in [DESIGN.md](DESIGN.md#project-roles).

- Joan is the Project Owner. Implement only the slice she has authorized; Joan decides accepted findings and performs the merge.
- Codex is the QA Engineer and Implementer. Work on a short-lived branch, keep changes reviewable, explain relevant design and implementation choices, and do not merge your own work.
- Claude is the Reviewer and Design Advisor. Claude may comment on a PR or Trello card when its connected tools allow, but does not edit files, commit, push, or merge.
- Keep the site-first scope: implement the portfolio presentation before adding QA Lab projects or test artifacts.
- Use role labels only to make responsibility clear. They do not change the account that GitHub or Trello records as the author. Do not claim an agent identity unless the platform shows a separate authenticated identity.
- Never put confidential employer materials, credentials, private URLs, raw CVs, personal contact details, or unapproved personal information in this public repository.
